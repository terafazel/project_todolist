# Productive Todo - Pomodoro Focus

A hand-drawn style web application that combines task management with the Pomodoro Technique to boost productivity and maintain focus during work sessions.

## 🚀 Features

### Core Functionality
- **Task Management**: Add, complete, and delete tasks with ease
- **Task Types**: Support for "Small Tasks" (with individual timers) and "Big Tasks" (broken down into subtasks)
- **Pomodoro Integration**: Built-in 25-minute (default) focus sessions for concentrated work
- **Subtasks**: For Big Tasks, create subtasks with their own dedicated timers

### Productivity Tools
- **Statistics Tracking**:
  - Total tasks created
  - Completed tasks
  - Pomodoros completed today
  - Productivity streak counter
- **Visual Progress**: Overall progress bar and subtask-specific progress bars
- **Motivational Quotes**: Random inspirational quotes to keep you motivated

### User Experience
- **Hand-Drawn Aesthetic**: Notebook-style design with charming doodles and sketches
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Persistence**: Automatic saving using browser local storage
- **Notifications**: Browser notifications for completed Pomodoro sessions
- **Real-time Updates**: Dynamic UI updates without page refreshes

### Advanced Features
- **Timer Controls**: Pause, resume, and stop active timers
- **Priority Levels**: High, Medium, and Low priority tasks
- **Task Timer Display**: Visual countdown for active tasks
- **Subtask Progress**: Individual completion tracking for subtasks

## 📋 How It Works

1. **Add Tasks**: Enter a task name, select type (Small/Big), set priority, and timer (for Small tasks)
2. **Break Down Big Tasks**: Add subtasks with individual names and timers for complex projects
3. **Start Pomodoro**: Click on a task to select it, then start the Pomodoro timer for focused work
4. **Work in Sessions**: Complete 25-minute work sessions with optional breaks
5. **Track Progress**: Monitor your productivity with built-in statistics and progress bars
6. **Complete Tasks**: Check off completed tasks and subtasks

## 🛠️ Installation & Usage

### Requirements
- Modern web browser with JavaScript enabled
- No additional software or dependencies required

### Running the App
1. Download or clone the repository
2. Open `todo-app.html` in your web browser
3. Start adding tasks and using the Pomodoro timer

## 🏗️ Technical Details

### Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with hand-drawn aesthetic
- **Storage**: Browser Local Storage for data persistence
- **Animations**: CSS animations for interactive elements

### Architecture
- Single-page web application
- Inline CSS and JavaScript for simplicity
- Event-driven JavaScript for dynamic interactions
- Modular function-based code structure

## 📊 App Structure

The application features a clean, intuitive interface with:
- **Header**: App title and productivity statistics
- **Task Input Section**: Form to add new tasks
- **Active Timer Display**: Shows currently running Pomodoro session
- **Task List**: Scrollable list of all tasks with subtasks
- **Progress Visualization**: Overall completion progress
- **Motivational Quotes**: Random quotes for inspiration

Inspired by traditional notebooks and productivity journals, the app features:

- Notebook-style lined background
- Pencil-themed color scheme
- Sketch-like animations and transitions
